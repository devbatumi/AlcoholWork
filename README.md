# AlcoholWork — Корабль трезвости

«Корабль трезвости» — веб-приложение, которое превращает каждую невыпитую порцию алкоголя в доску корабля. 1320 досок за 66 дней — и корабль уплывает за горизонт.

Базируется на научных принципах формирования привычек: Lally et al. (UCL 2010) — 66 дней до автоматизма поведения.

## Быстрый старт

```bash
npm install
npm run dev
```

## Стек
- React 18 + TypeScript
- Vite
- LocalStorage (без бэкенда — всё хранится в браузере)
