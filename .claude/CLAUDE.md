# AlcoholWork — Корабль трезвости

## Цель
Веб-приложение против алкогольной зависимости. Превращает каждую невыпитую порцию в доску корабля. 1320 досок за 66 дней = автоматизация привычки.

## Стек
- Язык: TypeScript
- Фреймворк: React 18 + Vite
- БД: LocalStorage

## Команды
```bash
npm install
npm run dev
npm run build
```
